# Contributing to HeyNaj Flow

Thanks for helping improve HeyNaj Flow.

This public repository is primarily for product feedback, documentation, bug reports, and feature suggestions.

## Bug reports

Please include:

- expected behavior
- actual behavior
- steps to reproduce
- browser/device information when relevant
- screenshots when useful

Remove personal information, credentials, API keys, customer data, and other sensitive information before posting.

## Feature requests

Explain the problem, who would benefit, the expected behavior, and why the change would be useful.

## Security

Do not file public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md).

## Code contributions

The production HeyNaj Flow platform is not published in this repository. Public participation does not imply that private production source code is available for redistribution or modification.
