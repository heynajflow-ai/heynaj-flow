# Code of Conduct

HeyNaj Flow welcomes constructive product feedback, bug reports, feature ideas, and community discussion.

## Our standards

Please:

- be respectful and professional
- keep discussions relevant to HeyNaj Flow
- describe problems and suggestions clearly
- respect the privacy of other users and businesses
- remove credentials, customer data, and other sensitive information before posting

Please do not:

- harass, threaten, or personally attack others
- post spam or intentionally disruptive content
- publish passwords, API keys, access tokens, private customer information, or other secrets
- post malicious payloads or instructions intended to compromise users or systems
- publicly disclose sensitive security vulnerabilities

## Security reports

Security vulnerabilities should not be posted as ordinary public issues.

Please follow [SECURITY.md](SECURITY.md) for responsible reporting.

## Moderation

Repository maintainers may edit, hide, lock, or remove content that violates these guidelines, and may restrict participation when necessary to protect the community or the project.

## Scope

These expectations apply to participation in the public HeyNaj Flow repository and its associated issue and discussion areas.
