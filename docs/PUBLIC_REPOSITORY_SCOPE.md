# Public Repository Scope

This repository is intentionally separated from the private HeyNaj Flow production platform.

## Appropriate public content

- README and product documentation
- public product updates
- issue templates
- feature requests
- approved public screenshots and media
- launch information
- community guidance

## Keep private

Do not publish production source code unless explicitly approved, Cloudflare secrets, provider credentials, API keys, authentication secrets, customer data, customer Knowledge files, internal runbooks, private security implementation details, database exports, or environment files.

## Licensing

No open-source license is included by default.

Publishing documentation or enabling public Issues does not automatically grant permission to copy, redistribute, modify, or reuse the private HeyNaj Flow product source code.
