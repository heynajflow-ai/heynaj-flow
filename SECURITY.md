# Security Policy

Do not post sensitive security reports publicly as GitHub Issues.

For security concerns, contact HeyNaj Flow privately through the official contact channel listed at:

https://heynajflow.com/

Include a clear description, affected feature, safe reproduction steps, and the potential impact.

Never publish API keys, passwords, access tokens, customer data, private workspace information, Cloudflare credentials, provider credentials, or private infrastructure details.

This public repository does not contain the private HeyNaj Flow production platform or customer runtime source code.
