## Repository policy

The video itself is not committed to normal Git history.

Cloudinary is the primary host so the repository stays lightweight and the same public video can be reused by the HeyNaj Flow website, documentation, and launch materials.

If a repository-local video copy is ever added later, place it in this folder and use a clear filename such as:

`heynaj-flow-launch-demo.mp4`

Only approved public media should be placed here. Do not include customer data, credentials, private workspace information, or internal infrastructure details.
